# 📋 Sistema de Gestão de Atividades

Projeto desenvolvido para aplicar, de forma prática, conhecimentos adquiridos durante a formação em Ciência da Computação.

## 🎯 Objetivo

O sistema permite cadastrar e acompanhar atividades de um projeto, facilitando a organização das tarefas e o acompanhamento do progresso.

## 🚀 Funcionalidades

- Cadastro de atividades
- Edição e exclusão
- Definição de prioridade
- Controle de status
- Busca por atividade
- Filtros por status e prioridade
- Indicador de progresso
- Armazenamento com LocalStorage
- Interface responsiva

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git e GitHub

## 📚 Conhecimentos aplicados

- Estruturação de páginas web
- CSS responsivo
- Lógica de programação
- Manipulação do DOM
- Eventos em JavaScript
- Persistência de dados no navegador
- Organização de código
- Git e GitHub
- Testes e resolução de problemas

## 💡 Aprendizados

O desenvolvimento deste projeto permitiu transformar conhecimentos teóricos em uma aplicação funcional, trabalhando organização, análise de requisitos, resolução de problemas e desenvolvimento de funcionalidades.

A experiência também contribuiu para o desenvolvimento de uma postura mais profissional, com foco em organização, documentação e melhoria contínua.
